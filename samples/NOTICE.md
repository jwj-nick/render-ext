# Sample file provenance

These files exist to exercise the viewers with realistic input. Two of them are
third-party; the rest are mine or synthetic.

## Third-party

| File | Source | License |
|---|---|---|
| `NV_NVDLA_cmac.v` (44 KB) | [NVDLA Open Source Project](https://github.com/nvdla/hw) — `vmod/nvdla/cmac/` | © 2016–2017 NVIDIA Corporation, [NVDLA Open Hardware License](https://github.com/nvdla/hw/blob/master/LICENSE) |
| `NV_NVDLA_CMAC_CORE_mac.v` (400 KB) | same | same |
| `NV_NVDLA_CMAC_CORE_active.v` (2.1 MB) | same | same |

Each file keeps its original NVIDIA copyright header. They are included
unmodified as realistic Verilog input — 44 KB for ordinary highlighting,
400 KB for a heavier file, and 2.1 MB to exercise the size threshold where
highlighting switches off. Get the originals, and the full license text, from
the NVDLA repository linked above.
